# Tech & AI Job Search Dashboard

A lightweight job search dashboard for exploring opportunities across leading technology and AI companies.

## Features

- Searchable directory of 25 technology and AI companies
- Job opportunity tracker
- Application status management
- Salary range tracking in CAD
- Search and filtering
- Browser-based data storage using localStorage

## Getting Started

1. Open the live dashboard (once published).
2. Browse the company directory.
3. Add job opportunities to your tracker.
4. Update application statuses as you progress.

## Built With

- HTML
- CSS
- JavaScript
- Browser Local Storage

## Privacy

The dashboard runs in the browser. Job entries are stored locally on the user's device and are not shared with a central database.
